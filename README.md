# Genshin auto skip macro
bro, i spent 3 hours of my life on this, and I didn’t fix many bugs, so yeah.

## Features
* **auto skip dialogue** - It checks in real time whether you are on a screen with a dialogue or not, using two verification methods.
* **support RU/ZH language** - Yes, if you know any of these languages or don’t speak English, you can change the language in the “Information” tab (the GUI might be buggy)

## Requirements

* **Windows** 10/11
* **AutoHotkey:** [AutoHotkey v2.0](https://www.autohotkey.com/) (Required. Do not use v1.1)
* **Windows Settings:**
  * Recommended Screen Resolution: **1920x1080**
  * Windows Scaling: **100%** (strictly required)
  * **OCR Language:** The English (US) Windows Language Pack must be installed for screen text recognition (OCR) to function properly.

## Installation
1. Download the latest release `.zip`.
2. Extract **all files** to a folder (do not run the script directly from the ZIP file).
3. Install [AutoHotkey v2.0](https://www.autohotkey.com/).
4. Run `Main.ahk`.
